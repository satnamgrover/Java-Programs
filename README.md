## Requirements

- Java Development Kit (JDK) 8 or higher
- Any IDE (IntelliJ IDEA, Eclipse, VS Code) or a terminal

Check your installation:

```bash
java -version
javac -version
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/satnamgrover/Java-Programs.git
   cd your-repo-name
   ```

2. Navigate to the program's folder, then compile and run:
   ```bash
   javac FileName.java
   java FileName
   ```

   Or simply open the project in your IDE and run the `main` class.
